== LOW-MEMORY DEPLOYMENT RECOMMENDATION ==
  It is SAFE on 4GB *for memory*: searxng RSS ~156-159MiB, engine count barely
  moves RSS (engine table is ~1KB/entry). Leave ~3.8GB for the model runtime.
  DEFAULT ENGINE LIST IS NOT SAFE FOR LATENCY: a single reachable-but-slow engine
  (observed: wikidata ~6s) inflates every query because SearXNG waits for the
  slowest engine. Ship the ~14-engine allowlist + outgoing.request_timeout=8s.
  Also throttle: brave suspends after rapid queries (seen: 'too many requests');
  DuckDuckGo can serve CAPTCHA. Keep >=2s between searches on a shared IP.
